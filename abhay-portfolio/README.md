# Abhay Kashinath, portfolio

UX and interface design portfolio: AI design and automation, UI UX design, and other design and freelance work.

A static site with no build step. Open `index.html` in a browser to view it locally.

## Publish with GitHub Pages

1. Upload these files to the root of a repository.
2. In the repository, go to **Settings › Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, pick `main` and `/ (root)`, then **Save**.
4. The site goes live at `https://<your-username>.github.io/<repository-name>/` after a minute or two.

## Resume

The Resume buttons link to `resume.pdf`. Add your resume to the root of the repository with that exact name.
